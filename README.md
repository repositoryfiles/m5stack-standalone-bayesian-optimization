# M5Stack単体でのベイズ最適化

二輪倒立振子のPDゲインを、外部PCとの通信なしで自動探索するMicroPythonの実験コードです。ガウス過程回帰（RBFカーネル、コレスキー分解）とLCB獲得関数を実装しています。NumPy等は不要です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| bayes_opt.py | ベイズ最適化の共通モジュール |
| test_bo.py | 二次関数の最適化（実験条件から再構成したコード） |
| test_bo_advanced.py | 多峰性関数、ノイズ付き関数とランダム探索の比較 |
| test_bo_recheck.py | ノイズ付き関数の候補再評価 |
| core2_pd_bayes_standalone.py | 二輪倒立振子の実機探索 |
| data/ | 予備実験と実機3セットの元CSV |

## 環境

M5Stack Core2、UIFlow2 MicroPython、Thonny、Roller485 Lite 2個（I2C 0x64, 0x65）、起立用バンパー。実機コードは M5、machine、unit.Roller485Unit を使用します。PCはプログラム転送とログ回収に使用しますが、探索中の通信・計算には不要です。

## 実行方法

1. `bayes_opt.py` と実行したいスクリプトをCore2の `/flash` に保存します。
2. 既存の自動起動プログラムを停止し、Thonnyからスクリプトを実行します。予備実験はモータ不要です。予備実験のCSVは固定名で上書きされるため、必要なログは事前に退避してください。
3. 実機では車体を直立させAボタンでキャリブレーションし、バンパーに置いてAボタンで開始します。
4. 30回の探索後、Aボタンで確認試験を開始します。候補ごとに5回、候補が異なる場合は交互に試行します。
5. 推奨ゲインはThonnyのコンソールに表示されます。CSVは `/flash/bo_pendulum_001.csv` などの未使用番号で保存されます。

## 実機の設定

| 項目 | 値 |
|---|---|
| 制御周期 | 10 ms |
| 制御時間・評価区間 | 3 s・開始後1～3 s |
| Kp / Kd | 0～80 / 0～4 |
| 候補 | 21×21点 |
| 初期探索 / LCB探索 | 6 / 24回 |
| length_scale / noise / kappa | 0.25 / 0.01 / 2.0 |
| 起立失敗・転倒の評価値 | 10 |

評価値は姿勢角のRMS（度）。noiseは標準化した評価値の共分散行列への対角加算値です。最適化はモータ停止中に実行します。正常終了はコード上の起立・時間・停止条件による判定で、常に直立付近にあることを保証しません。

## 実験データ

`data/bo_pendulum_001.csv` ～ `003.csv` は実機ログです。phaseは initial、bayes、check_measured、check_predicted を表します。rmsは失敗時 -1、costは探索評価値、calc_msは計算時間（ms）です。予備実験ログも収録しています。test_bo.py は元のソースが手元にないため再構成したもので、元ログを生成したコードとの完全一致は未確認です。

## 安全上の注意

探索中は不安定なゲインでもモータが動きます。実機の構成・モータ方向・電流制限・バンパー・停止条件を確認し、監視下で実施してください。車輪や可動部に触れず、独立した電源遮断手段を確保してください。Aボタンはソフトウェア停止であり、計算中の短い押下や通信異常時の停止を保証しません。産業設備へそのまま適用するためのコードではありません。
